

This project is a build running on the [RobustToolbox](https://github.com/space-wizards/RobustToolbox), engine, developed by [Space Wizard Federation](https://github.com/space-wizards) & [Crystall Punk 14](https://github.com/crystallpunk-14/crystall-punk-14) developed by TheShuEd respectively. It is based on the original build of [Space Station 14](https://github.com/space-wizards/space-station-14), and rewritten into a new game.

## Building

1. Clone this repo.
2. Run `RUN_THIS.py` to init submodules and download the engine.
3. Compile the solution.

[More detailed instructions on building the project.](https://docs.spacestation14.com/en/general-development/setup.html)
